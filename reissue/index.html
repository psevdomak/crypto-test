Перевыпуск сертификата

Используйте тестовый токен. Стенд создаёт контейнеры с уникальными именами и может удалить только контейнеры, созданные им в этой вкладке.

Параметры прогона

Смена формата и мок API работают только для Рутокена. Чтобы проверить смену формата, выберите в нативном диалоге режим, отличный от ответа мока. При ошибке API стенд сохранит ключ в выбранном режиме.
