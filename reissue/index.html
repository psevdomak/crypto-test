Параметры прогона

На Windows пустой выбор использует CSP, а выбор обоих режимов ограничивает список смарт-картами. На остальных платформах пустой выбор разрешает CSP и PKCS#11.

Смена формата и мок API работают только для Рутокена. Чтобы проверить смену формата, задайте для первой генерации режим, отличный от ответа мока. При ошибке API стенд сохранит ключ в выбранном режиме.
