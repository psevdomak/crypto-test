Как работает динамическая генерация ключей с получением формата ключа от API

Используйте тестовый токен. Стенд создаёт контейнеры с уникальными именами и может удалить только контейнеры, созданные им в этой вкладке.

Параметры прогона

Если заранее определён один Рутокен, стенд запрашивает формат до генерации. С несколькими носителями сначала выберите токен в КриптоПро. Чтобы проверить вторую генерацию, выберите PKCS11 на Рутокене и задайте ответ мок API CSP.
