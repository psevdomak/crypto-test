Все тесты

Перевыпуск сертификата

Используйте тестовый токен. Стенд создаёт контейнеры с уникальными именами и может удалить только контейнеры, созданные им в этой вкладке.

Контрольные данные токена

Подключите только целевой токен, загрузите считыватели и укажите его режимы и аппаратный серийный номер. Затем можно подключить второй токен для проверки привязки.

Параметры прогона

В нативном диалоге выберите настроенный считыватель. Для проверки смены режима выберите режим, отличный от ответа мока. Отметьте, появился ли второй диалог выбора носителя.
